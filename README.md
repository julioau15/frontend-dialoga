# DiaLoga - Frontend

Este repositório contém o frontend web do DiaLoga, uma aplicação desenvolvida como parte do Trabalho de Conclusão de Curso (TCC).

O DiaLoga é uma plataforma que busca facilitar a interação e o acompanhamento entre pacientes e profissionais por meio da tecnologia.

---

## Repositórios do Projeto

O projeto está dividido em três aplicações:

* **Repositório principal:** [https://github.com/julioau15/backend-dialoga](https://github.com/julioau15/dialoga)
* **Backend:** [github.com/julioau15/backend-dialoga](https://github.com/julioau15/backend-dialoga)
* **Frontend:** [github.com/julioau15/frontend-dialoga](https://github.com/julioau15/frontend-dialoga)
* **Mobile:** [github.com/julioau15/mobile-dialoga](https://github.com/julioau15/mobile-dialoga)

---

## Sobre o Frontend

O frontend é responsável pela interface web do DiaLoga.

A aplicação permite que os usuários interajam com as funcionalidades da plataforma por meio de uma interface acessível, intuitiva e responsiva.

O frontend realiza a comunicação com o backend para o envio e recebimento das informações utilizadas pelo sistema.

---

## Objetivo

Desenvolver uma interface web que permita aos usuários utilizar as funcionalidades do DiaLoga de forma simples, organizada e intuitiva.

---

## Como Executar o Projeto

### 1. Clone o repositório

```bash
git clone https://github.com/julioau15/frontend-dialoga.git
```

### 2. Acesse a pasta do projeto

```bash
cd frontend-dialoga
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

Após iniciar o projeto, acesse o endereço informado pelo terminal.
